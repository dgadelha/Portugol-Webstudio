# Atalhos de teclado

Tudo no Portugol Webstudio pode ser feito pelo teclado. Ao passar o mouse sobre um botão, ou chegar nele com o **Tab**, a dica mostra o atalho dele.

No Mac, use **Cmd** no lugar de **Ctrl** nos atalhos do editor, e **Option** no lugar de **Alt**.

## Em qualquer lugar

| Atalho  | O que faz                   |
| ------- | --------------------------- |
| Alt + N | Abre uma aba de código nova |
| Alt + W | Fecha a aba aberta          |

## Numa aba de código

| Atalho        | O que faz                             |
| ------------- | ------------------------------------- |
| Ctrl + Enter  | Executa o programa                    |
| Ctrl + S      | Baixa o código como um arquivo `.por` |
| Ctrl + O      | Abre um arquivo do computador         |
| F1            | Abre a Ajuda                          |
| Ctrl + G      | Vai até uma linha                     |
| Ctrl + Espaço | Abre a lista de sugestões             |

## Escrevendo código

O editor é o mesmo do Visual Studio Code, e os atalhos dele funcionam. Alguns dos mais úteis:

| Atalho                        | O que faz                                    |
| ----------------------------- | -------------------------------------------- |
| Ctrl + F                      | Procura no código                            |
| Ctrl + H                      | Procura e substitui                          |
| Ctrl + /                      | Comenta ou descomenta as linhas selecionadas |
| Ctrl + Z / Ctrl + Y           | Desfaz e refaz                               |
| Ctrl + D                      | Seleciona a próxima ocorrência da palavra    |
| Alt + seta para cima/baixo    | Move a linha para cima ou para baixo         |
| Shift + Alt + seta para baixo | Copia a linha para baixo                     |
| Tab / Shift + Tab             | Aumenta ou diminui a indentação das linhas   |

## Nas abas

Com uma aba selecionada (clique nela, ou chegue nela com o **Tab**):

| Atalho                       | O que faz                           |
| ---------------------------- | ----------------------------------- |
| Seta para a esquerda/direita | Vai para a aba ao lado              |
| Home / End                   | Vai para a primeira ou a última aba |
| F2                           | Renomeia a aba                      |
| Delete                       | Fecha a aba                         |

Com o mouse, um duplo clique renomeia a aba e um clique com o botão do meio fecha.

## Nas listas e janelas

| Onde                      | Atalho                       | O que faz                                                                                       |
| ------------------------- | ---------------------------- | ----------------------------------------------------------------------------------------------- |
| Barra de ações            | Setas, Home e End            | Andam entre os botões                                                                           |
| Painel de baixo           | Seta para a esquerda/direita | Troca entre Saída e Problemas                                                                   |
| Exemplos                  | Seta para cima/baixo e Enter | Escolhem e abrem um exemplo                                                                     |
| Lista de tópicos da Ajuda | Setas, Home, End e Enter     | Andam entre os tópicos e abrem um deles. Digitar uma letra vai para o tópico que começa com ela |
| Janela de gráficos        | Esc                          | Fecha a janela e para o programa                                                                |
| Qualquer janela           | Esc                          | Fecha a janela                                                                                  |
