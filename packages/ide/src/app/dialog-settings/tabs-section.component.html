Reabrir as abas da última janela

Uma janela nova começa com o código da última fechada. Desativado, ela começa vazia e esse código fica em "Código de sessões anteriores", na aba inicial, para restaurar quando quiser.

O código de sessões anteriores fica guardado neste navegador por até {{ maxAgeDays }} dias. Quando passa de {{ maxRecoverable }} sessões, as mais antigas são apagadas.
