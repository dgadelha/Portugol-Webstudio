Sobre o Portugol Webstudio

@if (isBeta) { Beta }

O Portugol Webstudio é um ambiente de desenvolvimento integrado (IDE) online para a linguagem de programação Portugol (UNIVALI). Foi criado para facilitar o aprendizado de programação de computadores, permitindo que estudantes e professores possam escrever, compilar e executar programas de computador diretamente no navegador.
